# qSpot representative images: Figures 4a and 5a

The 24 photographs underlying the representative spot images in Figures 4a and
5a are already stored in `04_quantitative_spot_test/dataset/`. The links below
identify the originals and their corresponding SpotScanner CSV files; no images
are duplicated here. Each CSV contains the 24 positions in a four-row,
six-column spot array. The quantitative analyses use the complete replicate
sets described in the [repository README](../README.md#04_quantitative_spot_test),
not only the representative images listed here.

## Images and quantitative inputs

Within each analysis set, UV dose increases from left to right in the figure.
Dates below are camera-recorded capture dates, not inferred inoculation dates.
The experiment folder is part of the identifier: filenames can recur across
experiments. Image-series code 6 or 7 is not a universal concentration label;
use the strain-specific initial concentrations in the row table below.

suspension; columns 2–6 are successive fivefold dilutions from left to right.

provides the corresponding strain and genotype information. Table S3 lists
strains for the reversion assay and does not define the qSpot row mapping.
