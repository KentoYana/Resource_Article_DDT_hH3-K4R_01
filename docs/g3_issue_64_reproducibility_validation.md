## Reproduction results

- The killing-test beta-regression estimates, contrasts, and slope comparisons
  reproduced the committed numerical results.
- The reversion-assay AUC values and four Welch tests reproduced the committed
  numerical results.
- The sequence analysis reproduced 109 indels and the negative-binomial
  likelihood-ratio result (`p = 0.023`). Figure 3's integrated indel plot was
  reproduced byte-for-byte apart from its generated timestamp. The example
  sequence previously selected for each indel size was not reproducible because
  the script used unseeded random sampling; it is now selected deterministically
  by stable experimental identifiers. Counts, model inputs, model results, and
  Figure 3 are unaffected.
- All six qSpot analyses reproduced their committed model inputs and numerical
  results. For `mus-9`, four zero-control observations were excluded and 380
  observations were retained; each other target retained 288 observations.
  The regenerated raw input tables were identical after excluding the former
  machine-specific absolute-path column. That column now records a
  repository-relative path.
- The two Ferraro-only H3K4 output sets used by the manuscript reproduced
  byte-for-byte. The cross-study reporter and repair output sets reproduced
  with the current script's explicit study-labelled filenames and metadata;
  those names replace the legacy percentile filenames.
- Segregation summaries and both `pan-2`/PTHR20881 Clustal alignments were
  reproduced without changes.

Some R console-summary files omit interactive prompt lines when regenerated by
`Rscript`, and TikZ sources record their generation timestamp. These are
presentation/provenance differences rather than changes in data, model inputs,
or statistical results.

## Manuscript consistency boundary

The Ferraro-only H3K4 figure fragments in the manuscript and Resource
repositories are identical. Other manuscript TikZ files include deliberate
presentation-level edits or panel-specific subsets and are therefore not
expected to be byte-identical to the full generated Resource plots. Their
underlying numerical CSV outputs and the values stated in the manuscript must
remain the consistency criterion.

The current H3K4 analysis adds `IRanges`, `rtracklayer`, `digest`, and `jsonlite`
to `package_versions.csv`. The author approved adding those packages and their
standard software citations to the manuscript's supplemental package table on
2026-09-15; the Article repository records the change in commit `0062183`.
